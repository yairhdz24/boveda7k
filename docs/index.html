Modelo de seguridad

Cifrada antes de salir de tu navegador

Tu contraseña maestra nunca viaja. De ella se deriva una llave en tu navegador, esa llave cifra cada credencial y el servidor solo guarda texto cifrado.

  • Criptografía estándar. PBKDF2-SHA256 con 600,000 iteraciones y AES-256-GCM, con la Web Crypto API del navegador.
  • Tus datos, tu servidor. La despliegas en tu propio proyecto de Supabase. No hay un servicio central que guarde la bóveda de nadie.
  • Biometría de verdad. Cada dispositivo envuelve la llave con una passkey. Sin el dispositivo y tu huella o rostro, esa copia no sirve.
  • Honesta con sus límites. El código está abierto para revisión, pero aún no tiene una auditoría independiente. Si olvidas la contraseña maestra, no hay recuperación.

Tuya en 5 minutos

Necesitas Node 22 y un proyecto de Supabase; el plan gratuito alcanza.

~/boveda7k 
# 1 · clona e instala
$ git clone https://github.com/yairhdz24/boveda7k.git
$ cd boveda7k && npm install

# 2 · pega las migraciones de supabase/migrations en el SQL Editor
# 3 · copia tus llaves públicas de Supabase
$ cp .env.example .env.local

# 4 · listo
$ npm run dev
